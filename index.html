Abstract

A unified continuous foundation model for long-horizon spatial mapping and promptable episodic retrieval.

Autonomous mobile robots operating over long horizons must remember what they observed, where and when they observed it, and which visual evidence supports their answers. Existing memory systems often prioritize semantic retrieval over visual histories or metric structure through 3D scene graphs, leaving persistent object identity, temporal context, and fine-grained visual evidence insufficiently integrated. We introduce LOCI, a dual-memory framework that organizes robot experience into persistent object-centric 3D entities and temporally localized episodes. Object memory consolidates identity and metric geometry across observations, while episodic memory captures scene context, activities, and observed changes. Observation links connect entities to their supporting encounters, enabling an agent to combine spatial and temporal retrieval with targeted visual inspection when textual summaries are insufficient. We evaluate LOCI on LMEE-Bench and OC-NaVQA, covering simulated indoor and real-world outdoor environments. LOCI improves question- answering accuracy on the LMEE-Bench 58-task subset and full benchmark by 8.7% and 10.6%, respectively, and reduces spatial and temporal localization errors on OC-NaVQA by 14.9% and 53.6% relative to the most competitive baselines. Deployment on a Unitree G1 humanoid further demonstrates long-horizon memory retrieval and evidence-grounded reason- ing in a real-world office environment.

Topological Loci Indexing
Compresses continuous RGB-D and IMU trajectories into topological graph nodes with logarithmic lookup complexity \(\mathcal{O}(\log N)\).
Continuous Episodic Recall
Retains temporal context over 10,000+ execution steps while supporting natural language visual queries and temporal filtering.
Zero-Shot Navigation Policy
Directly translates memory embeddings into low-level humanoid velocity commands without fine-tuning on downstream environments.

Abstract

A unified continuous foundation model for long-horizon spatial mapping and promptable episodic retrieval.

Autonomous mobile agents and humanoid robots deployed in complex, dynamic environments require the ability to construct persistent spatial-temporal memories over extended operational timeframes. Traditional SLAM and visual-RAG models suffer from memory bloat, catastrophic forgetting, or high query latency when searching long-horizon trajectories. In this work, we introduce LOCI-Memory, a promptable behavioral foundation model that encodes continuous sensory-motor streams into a compact, topologically indexable Loci Memory Graph. By leveraging unsupervised reinforcement learning and spatial-temporal transformer embeddings, LOCI-Memory enables instant sub-millisecond object/location recall, zero-shot trajectory planning, and robust adaptation across multi-room environments without pre-mapped landmark annotations.

Topological Loci Indexing
Compresses continuous RGB-D and IMU trajectories into topological graph nodes with logarithmic lookup complexity \(\mathcal{O}(\log N)\).
Continuous Episodic Recall
Retains temporal context over 10,000+ execution steps while supporting natural language visual queries and temporal filtering.
Zero-Shot Navigation Policy
Directly translates memory embeddings into low-level humanoid velocity commands without fine-tuning on downstream environments.

System Architecture & Method

How LOCI-Memory processes sensory streams, indexes spatial loci, and executes prompt-driven trajectories.

Figure 1: End-to-end pipeline of LOCI-Memory showing sensory ingestion, spatial-temporal feature encoding, topological graph storage, and policy query execution.

1

Sensory Feature Ingestion

High-frequency visual and inertial data are streamed through spatial convolution backbones to extract geometric landmark features.

2

Temporal Compression

Redundant stationary frames are compressed using unsupervised reinforcement rewards, retaining only salient topological transitions.

3

Loci Graph Indexing

Nodes are dynamically linked via relative Euclidean and semantic similarity edges, allowing fast vector search over 10k+ steps.

4

Promptable Trajectory Recall

When given a text or visual target query, the agent performs A* search over latent loci nodes to compute optimal navigation sub-goals.

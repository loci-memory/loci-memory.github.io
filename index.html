LOCI: An Egocentric-Allocentric Dual Memory for Robotic Spatiotemporal Reasoning

Read the Paper Explore the Framework View Benchmarks

Abstract

Autonomous mobile robots operating over long horizons must remember what they observed, where and when they observed it, and which visual evidence supports their answers. Existing memory systems often prioritize semantic retrieval over visual histories or metric structure through 3-D scene graphs, leaving persistent object identity, temporal context, and fine-grained visual evidence insufficiently integrated. We introduce LOCI, a dual-memory framework that organizes robot experience into persistent object-centric 3-D entities and temporally localized episodes. Object memory consolidates identity and metric geometry across observations, while episodic memory captures scene context, activities, and observed changes. Observation links connect entities to their supporting encounters, enabling an agent to combine spatial and temporal retrieval with targeted visual inspection when textual summaries are insufficient. We evaluate LOCI on LMEE-Bench and OC-NaVQA, covering simulated indoor and real-world outdoor environments. LOCI improves question-answering accuracy on the LMEE-Bench 58-task subset and full benchmark by 8.7% and 10.6%, respectively, and reduces spatial and temporal localization errors on OC-NaVQA by 14.9% and 53.6% relative to the most competitive baselines. Deployment on a Unitree G1 humanoid further demonstrates long-horizon memory retrieval and evidence-grounded reasoning in a real-world office environment.

Framework & Introduction

A persistent object memory and a temporally indexed episodic memory work together to answer questions about what happened, where it happened, and when.

Why dual memory?

Long-horizon robots must connect an object's identity and metric location with the scene observed during a particular encounter. Observation-centric systems preserve visual history but leave identity and geometry implicit. Object-centric maps consolidate those properties, yet can lose transient activities and fine visual details.

LOCI connects both views. Persistent entities preserve identity and 3-D geometry across observations; episodic intervals preserve scene-wide context and change over time. The agent can move from compact summaries to the original visual evidence whenever a question requires details that were not captured in text.

Core contributions

  • Dual-memory representation: object-centric 3-D entities plus independently retrievable episodic intervals.
  • Evidence-grounded retrieval: explicit links connect each entity to the encounters and images that support it.
  • Cross-environment evaluation: simulated indoor trajectories, real-world outdoor sequences, component ablations, and Unitree G1 deployment.

Method Details

LOCI converts posed RGB-D observations into a linked memory graph, then retrieves only the evidence needed for each question.

Object memory G Episodic memory D Observation links E Memory graph H = (G, D, E)
1

Build object-centric 3-D memory

Qwen3-VL produces object descriptions, SAM3 segments instances, and DINOv2 encodes appearance. Depth and camera pose lift each mask into 3-D. Geometric overlap and visual similarity associate observations with persistent entities, whose point clouds, boxes, descriptors, and semantic descriptions are updated over time.

2

Build episodic memory

The observation stream is divided into 4-second intervals. Each interval stores its time span, a VLM summary, a text embedding, and RGB-D keyframes sampled at 1 Hz. This memory preserves activities, scene context, and changes that an object-level representation cannot capture alone.

3

Connect entities to encounters

Observation links record the intervals and source views in which each entity appeared, together with view-quality scores. These links let the agent recover an object's persistent state, revisit a specific encounter, and inspect the surrounding scene.

4

Retrieve and reason over evidence

The agent combines entity search, two-stage episodic retrieval, entity-view retrieval, and interval inspection. A reranker narrows 20 episodic candidates to the top 3; GPT-4o can make up to 12 tool calls before producing an evidence-grounded answer.

Real-World Deployment

LOCI runs with a Unitree G1 humanoid in an office environment, connecting natural-language queries to grounded observations and navigation targets.

RGB-D observations and pose estimates stream from the robot to an external RTX 5090 workstation for perception and memory processing. The grounded 3-D target returns through ROS 2 to onboard Nav2 for planning and execution on the Jetson AGX Orin.
